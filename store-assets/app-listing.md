# 로또 번호 연구소 앱 등록 정보 (앱인토스 콘솔 입력용)

## 기본
- 한글 앱 이름: 로또 번호 연구소
- 영문명(appName): numberlab (변경 불가)
- 영문 표시 이름: Number Lab
- 앱 유형: 비게임
- 사용 연령: 만 19세 이상

## 부제
역대 번호 통계와 번호 생성

## 상세 설명
로또 6/45의 역대 회차별 번호 기록과 번호별 통계를 확인하고, 통계 기반 또는 랜덤 방식으로 번호를 생성해 볼 수 있는 서비스입니다. 앱에 들어오면 번호 생성 화면에서 숫자가 섞이다가 번호로 확정되고, 아래에서 최근 회차의 번호와 출현 빈도 분석, 자리별 빈도 분석, 회차별 기록을 볼 수 있습니다. 처음 1회는 광고 없이 만들 수 있고, 이후에는 광고를 끝까지 보면 번호를 만들 수 있습니다. 재미를 위한 서비스이며 복권 구매나 베팅과 연결되지 않고, 통계 기반 추천도 확률을 높이지 않습니다.

## 출시 노트 (최신 버전: 광고 연동, 번호 타일 디자인)
로또 번호 연구소가 더 편해졌어요.
- 번호가 연구실 시료 칸처럼 깔끔한 타일 모양으로 바뀌었어요.
- 번호를 만들 때 처음 1회는 광고 없이 만들 수 있어요. 이후에는 광고를 끝까지 보면 번호를 만들 수 있어요.
- 한 번에 하나의 번호를 만드는 방식으로 단순하게 정리했어요. (5게임 생성과 효과음은 없어졌어요.)
- 회차별 기록과 최신 회차 화면의 표현을 알기 쉽게 다듬었어요.
- 광고가 더 안정적으로 불러와지도록 개선했어요.

재미를 위한 서비스이며, 복권 구매나 베팅과 연결되지 않아요. 통계 기반 추천도 확률을 높이지 않아요.

### 짧은 버전
- 번호가 시료 타일 모양으로 바뀌었어요.
- 처음 1회는 광고 없이, 이후에는 광고를 끝까지 보면 번호를 만들 수 있어요.
- 5게임 생성과 효과음을 정리하고 화면 표현을 다듬었어요.

### 이전 버전
로또 번호 연구소를 새롭게 바꿨어요.
- 연구소 느낌의 새 디자인과 라이트 모드를 추가했어요.
- 회차별 기록과 빈도 분석 화면을 정리했어요.

- 기능 이름에는 당첨, 추첨, 상금, 1등, 확률, 예측, 적중, 베팅 같은 단어를 쓰지 않는다.

## 인앱 광고 (보상형)
- 광고 종류: 보상형. 앱을 열 때마다 처음 1회의 번호 생성은 광고 없이 무료이고, 이후 번호 생성부터 광고를 끝까지 본 경우에만 생성한다(5게임과 번호 고정/제외 광고 구분은 없앴다).
- 무료 횟수는 `REACT_APP_AD_FREE_GENERATIONS`(기본 1, 0이면 처음부터 매번 광고)로 바꾼다. 생성에 성공했을 때만 무료 횟수를 소모한다.
- 보상은 userEarnedReward 이벤트를 받았을 때만 지급하고, 광고가 준비되지 않았거나 실패하면 광고 없이 진행한다.
- 광고가 필요한 버튼은 '광고 보고 번호 생성하기'로 표시하고 안내 문구를 둔다.
- 광고 그룹 ID(보상형 운영): ait.v2.live.a577ec24573b4444 (클라이언트에 포함되는 값이며 비밀이 아님)
- 빌드: 테스트 `npm run build:ait:ad-test`(보상형 테스트 ID만 사용), 운영 `npm run build:ait:release`
- 전면형 그룹을 쓰려면 `REACT_APP_AD_TYPE=interstitial`을 함께 지정한다. 종류가 어긋나면 보상이 무시되거나 영영 진행되지 않는다.
- 광고는 샌드박스로 확인할 수 없으므로 콘솔 출시 QR로 토스 앱에서 테스트한다. 테스트에는 반드시 테스트 ID만 쓰고, 운영 ID로 사전 테스트하지 않는다.
