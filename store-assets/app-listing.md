# 번호 연구소 앱 등록 정보 (앱인토스 콘솔 입력용)

## 기본
- 한글 앱 이름: 번호 연구소
- 영문명(appName): numberlab (변경 불가)
- 영문 표시 이름: Number Lab
- 앱 유형: 비게임
- 사용 연령: 만 19세 이상

## 부제
역대 번호 통계와 번호 생성

## 상세 설명
로또 6/45의 역대 당첨 번호와 번호별 통계를 확인하고, 통계 기반 또는 랜덤 방식으로 번호를 생성해 볼 수 있는 서비스입니다. 앱에 들어오면 번호 생성 화면에서 숫자가 섞이다가 번호로 확정되고, 아래에서 최근 회차의 당첨 번호와 출현 빈도 분석, 자리별 빈도 분석, 회차별 당첨 기록을 볼 수 있습니다. 재미를 위한 서비스이며 복권 구매나 베팅과 연결되지 않고, 통계 기반 추천도 당첨 확률을 높이지 않습니다.

## 출시 노트 (첫 버전)
번호 연구소를 처음 선보여요.
- 번호 생성: 통계 기반 또는 랜덤 방식으로 번호를 만들 수 있어요.
- 당첨 번호 조회: 역대 회차별 당첨 번호를 확인할 수 있어요.
- 빈도 분석: 가장 많이 나온 번호와 자리별 상위 번호를 볼 수 있어요.

재미를 위한 서비스이며, 복권 구매나 베팅과 연결되지 않아요. 통계 기반 추천도 당첨 확률을 높이지 않아요.

## 주요 기능 (한글 10자 이내 / 영문 15자 이내, 첫 글자만 대문자, 기호는 : . 만)
| 한글 | 영문 |
|---|---|
| 번호 생성하기 | Create numbers |
| 회차별 기록 보기 | Draw history |
| 빈도 분석 보기 | Frequency stats |

- 콘솔에서 '당첨 번호 보기'가 사행성 표현 의심으로 안내돼 '회차별 기록 보기'로 바꿨다. 대체 후보: 지난 회차 보기(Past draws), 회차 결과 보기(Draw results), 최신 회차 보기(Latest draw).
- 기능 이름에는 당첨, 추첨, 상금, 1등, 확률, 예측, 적중, 베팅 같은 단어를 쓰지 않는다.
